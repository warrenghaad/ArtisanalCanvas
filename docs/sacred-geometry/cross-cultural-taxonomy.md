# Cross-Cultural Sacred and Aesthetic Geometry Taxonomy

This taxonomy expands the repo from a small mandala set into a world geometry studio. It is built for drawing practice, source research, pattern generation, and future infinite-canvas concept cards.

## How to read this taxonomy

Each entry uses five lenses:

| Lens | Meaning for ArtisanalCanvas |
| --- | --- |
| Geometry family | The transferable visual rule: radial symmetry, tessellation, grid, interlace, spiral, lattice, fractal, proportion, etc. |
| Cultural context | Where the form appears and what kind of object, building, manuscript, textile, map, or ritual surface carries it. |
| Sacred or aesthetic status | Sacred, cosmological, devotional, funerary, civic, architectural, textile, scientific, or aesthetic. |
| Drawing translation | How students reduce it into primitives, construction lines, repeat units, axes, or pattern logic. |
| Visualization need | What asset the app should eventually show: reference image, overlay, worksheet, SVG diagram, raster texture, Canvas interaction. |

**Important caution:** not every geometric form is automatically mystical. When the cultural or ritual role is uncertain, label it as aesthetic, architectural, material, civic, or decorative rather than forcing a sacred reading.

## 1. Core transferable geometry families

These are the reusable drawing engines that cut across regions.

| Family | Visual engine | Drawing primitives | Good first visualization |
| --- | --- | --- | --- |
| Center and circle | point, radius, circumference, boundary | dot, circle, compass arc | SVG compass-circle sheet |
| Radial symmetry | repeated rotation around a center | circle, wedge, spoke, ring | mandala/star worksheet |
| Bilateral symmetry | mirrored left/right structure | centerline, pair, reflection | mirrored vessel or mask overlay |
| Orthogonal grid | measured rows and columns | square, rectangle, module | construction grid overlay |
| Diagonal grid | diamonds, lozenges, secondary axes | 45-degree line, rhombus, zigzag | lattice worksheet |
| Star polygon | crossing polygon families | circle, regular polygon, chord | 6/8/10/12-point star diagrams |
| Tessellation | repeat unit with no gaps | polygon, translation, rotation | repeat-unit animation |
| Strapwork and interlace | over-under woven line logic | band, knot, crossing, bridge | color-coded over-under diagram |
| Meander and key fret | angular path with repeated turns | line, right angle, step | continuous-path worksheet |
| Spiral and volute | rotating growth or curling motion | center, curve, expanding radius | spiral/cone/ribbon diagram |
| Rosette and palmette | petal repetition from a center or stem | oval, teardrop, wedge, axis | petal-count construction sheet |
| Lattice and screen | visible voids generated by repeat units | bar, node, opening, frame | jali/window cutout diagram |
| Muqarnas and cellular vaulting | stacked cells and faceted niches | cell, tier, half-dome, prism | sectional diagram and 3D blockout |
| Proportional canon | body, building, or page governed by ratios | grid, module, division | proportion ruler overlay |
| Perspective grid | depth organized by horizon and vanishing point | box, plane, ray, horizon | one-point/two-point grid |
| Fractal/self-similar pattern | small-scale form echoes large-scale form | branching, repetition, nesting | settlement/textile zoom sequence |
| Cosmogram/calendar wheel | world order or time mapped as geometry | axis, quadrant, ring, center | labeled wheel diagram |

### Key concept set

| Concept ID | Geometry | Cultural surfaces | Sacred/aesthetic status | Drawing translation | Visualization need |
| --- | --- | --- | --- | --- | --- |
| mesopotamia-rosette-star | rosette, 6/8-point star, petal rotation | seals, reliefs, temple ornaments, goddess/star symbolism | often sacred or royal when tied to divinities and power | center point, ring, equal wedges, petal ovals | reference board, radial SVG, carved relief overlay |
| mesopotamia-cylinder-seal-repeat | repeat band, narrative frieze, register | cylinder seals rolled into clay | civic, ritual, administrative, mythic | long strip, repeated figure blocks, negative-space rhythm | rolling-seal animation, repeat band worksheet |
| mesopotamia-stepped-ziggurat | stacked rectangle, terrace, axis | ziggurat architecture | sacred architecture and city focus | stacked boxes, horizon, vertical axis, decreasing modules | perspective blockout, section diagram |
| mesopotamia-cuneiform-grid | wedge marks in tabular grid | tablets, accounting, lists, astronomical records | civic, literary, scientific, ritual depending on text | row/column grid, wedge direction, pressure marks | clay tablet texture sheet, wedge mark drill |
| mesopotamia-guilloche-band | braided band, wave interlace | borders, seals, metalwork | aesthetic, protective-border logic | two crossing sine paths, over-under rhythm | braided border SVG, over-under overlay |

### Drawing lesson arc

1. Start with a clay-tablet rectangle and divide it into rows.
2. Add wedge marks as directional primitives.
3. Move to cylinder-seal bands: draw a horizontal register, repeat a motif, then vary scale.
4. Build a ziggurat with stacked boxes in two-point perspective.
5. Add a rosette/star as a sacred or royal emblem, but label context carefully.

Islamic geometry is ideal for a multi-level learning progression:

1. Draw a circle grid.
2. Construct polygons.
3. Extract star and rosette.
4. Turn polygons into repeat units.
5. Add strapwork and over-under logic.
6. Add border hierarchy.
7. Convert flat repeat to architectural surface: wall, dome, screen, vault, floor.

## 15. Assessment prompts

Use these in drawing assessment or AI feedback.

1. **Structure:** Can the student identify the center, axis, module, repeat unit, or grid?
2. **Construction:** Did they build the pattern from primitives rather than copying contour noise?
3. **Cultural context:** Did they label the pattern as sacred, civic, textile, architectural, or aesthetic with evidence?
4. **Variation:** Can they transform the same geometry into another material surface?
5. **Perspective:** Can the flat pattern be placed onto a floor, wall, dome, vase, cloth fold, or screen?
6. **Source care:** Did they distinguish between original generated diagrams, museum references, and culturally specific symbols?
