# Primitive Generative Drawing

## Status

Seed progression.

## Not Required Clause

Primitive Generative Drawing is one optional progression in the Line All Richie progression registry. It is not the required curriculum spine. Use it only when the learner chooses this route or when the lesson specifically asks how line, shape, pattern, value, and form can generate an image.

## Purpose

This progression teaches drawing as generative construction. Instead of drawing an object first and then adding pattern, the learner grows the object from marks, shapes, patterns, values, forms, and transformations.

## Core Question

What happens when line, shape, and pattern become material rather than decoration?

## Primitive Roles

| Role | Function | Example |
| --- | --- | --- |
| Object | The primitive is the thing seen | circle as sun |
| Material | The primitive builds the thing | spirals building hair |
| Surface | The primitive describes a carrier | triangles wrapping a vase |
| Light | The primitive creates value and depth | hatching turning a cheek |

## Core Formula

```txt
primitive + operation + carrier form + visual function = manufactured image
```

## Phases

1. **Isolate**: use one primitive only.
2. **Operate**: repeat, rotate, reflect, scale, nest, interlock, compress, stretch, wrap, fracture, fade, or invert figure-ground.
3. **Manufacture**: use the primitive to create a representational subject.
4. **Historical Copy**: copy a pattern family as grammar, such as meander, rosette, star, knot, arabesque, herringbone, or op grid.
5. **Mutate**: change the pattern without losing its rule.
6. **Deform Into Space**: place the pattern on a sphere, cylinder, folded surface, face, glass, room, or impossible object.

## Study Card Template

```md
**Primitive:** line / curve / circle / triangle / square / spiral / wave
**Operation:** repeat / rotate / reflect / scale / interlock / compress / wrap
**Carrier:** face / vase / hand / cloth / glass / cube / room / impossible object
**Function:** contour / shadow / surface / volume / rhythm / emotion / identity
**Historical pattern:** meander / rosette / star / knot / arabesque / herringbone / op grid
**Mutation:** what changed?
**Deformation:** flat / cylinder / sphere / folded / refracted / perspective / impossible
**Recovery invariant:** what must remain readable?
```

The learner can select a primitive, choose an operation, assign a carrier form, create surface or light through repetition, mutate a pattern, and deform it across a believable surface.
