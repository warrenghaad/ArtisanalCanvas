# Progression Registry

This folder stores optional learning progressions for Line All Richie.

A progression is a selectable route through a family of drawing problems. It is not a universal order. The learner may enter, pause, repeat, skip, braid, or invert a progression.

## Required Rule

Every progression file must include a **Not Required Clause**.

The clause should say that this progression is optional and should not be treated as the required curriculum spine unless the user explicitly asks to follow it.

## Progression File Shape

Use this shape for every progression:

```md
# Progression Name

## Status

## Not Required Clause

## Purpose

## What This Progression Trains

## Entry Conditions

## Phases

## Study Card Template

## Sample Drills

## Visual Maps Needed

## Compatible Progressions

## Exit Skills

## GitHub Routing

## Running Project Sum
```
