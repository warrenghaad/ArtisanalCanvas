# Agent Swarm

The Line All Richie swarm is a lightweight curriculum-production system. It is not a fictional committee for its own sake. Each agent owns a specific cognitive job in the drawing curriculum pipeline.

## Swarm Objective

Turn an input such as:

```txt
Level 5, public cafe scene, hidden antipathy, 5-minute exercise
```

into a finished GitHub artifact with:

- a clear skill target
- a visual explanation
- a practical drawing task
- a Control -> Bend -> Recover variation
- critique criteria
- file path and ledger update

## Agent Roster

| Agent | Primary Job | Output |
| --- | --- | --- |
| Studio Director | Selects the next best learning move | learning objective and sequence |
| Curriculum Architect | Converts the objective into a lesson arc | lesson outline and progression |
| Form & Volume Coach | Grounds the lesson in forms, axes, planes, and perspective | construction logic |
| Expression Analyst | Breaks emotion into movable face/body structures | expression map |
| Texture & Emotion Agent | Turns feeling into line, edge, density, and texture rules | mark system |
| Public Sketching Field Agent | Makes the exercise usable in public spaces | time-boxed field drill |
| Line & Markmaking Coach | Tunes pressure, rhythm, speed, overlap, interruption | line protocol |
| Critique Agent | Tests readability, specificity, and next drill | critique checklist |
| Visual Reference Curator | Suggests references and visual traditions | reference brief |
| Animation Studio Lead | Converts reusable visuals into component specs | component candidate |
| GitHub Librarian | Saves artifacts, updates ledger, maintains paths | repository-ready Markdown |

## Swarm Handoff Order

1. **Intake**: GitHub issue or chat request defines level, subject, emotional focus, and output type.
2. **Direction**: Studio Director picks one anchor skill.
3. **Architecture**: Curriculum Architect creates the lesson spine.
4. **Specialist passes**: Form, expression, texture, line, public-sketching, and reference agents add only what the lesson needs.
5. **Visual pass**: A visual map, storyboard, table, labeled diagram, or component spec is required.
6. **Critique pass**: Critique Agent checks the artifact for drawability and progression.
7. **Export pass**: GitHub Librarian saves the artifact and updates the ledger.

## Definition of Done

A curriculum artifact is done when it contains:

- title and purpose
- level on the Core Drawing Ladder
- one anchor skill
- one structural constraint
- one concrete drawing task
- one controlled rule bend
- one recovery condition
- visual explanation
- critique checklist
- suggested repo path
- Running Project Sum

## Anti-Drift Rules

- No isolated tips without a task.
- No spatial explanation without a visual skeleton.
- No texture talk without emotional or structural function.
- No expression lesson without brow, eye, mouth, jaw, tilt, gaze, or posture mechanics.
- No public sketching task that depends on identifiable portrait capture.
- No curriculum export without a suggested filename.
