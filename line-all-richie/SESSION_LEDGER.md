## Decisions Made

- The canonical project folder is `line-all-richie/`.
- Curriculum material will be produced through named specialist agents.
- Every artifact should include a drawing task, visual explanation, critique path, and suggested GitHub location.
- The core teaching loop is **Control -> Bend -> Recover**.
- The curriculum ladder has ten levels: marks, primitive forms, combined forms, planes and perspective, expression, emotional texture, public-scene composition, narrative compression, revision, and personal visual language.
- Visual explanations should use labeled diagrams, visual maps, storyboards, thumbnail plans, or component specs.
