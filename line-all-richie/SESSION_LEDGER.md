## Decisions Made

- The canonical project folder is `line-all-richie/`.
- Curriculum material will be produced through named specialist agents.
- Every artifact should include a drawing task, visual explanation, critique path, and suggested GitHub location.
- The curriculum is a **progression registry**, not one required ladder.
- A progression is a selectable route through a drawing problem family.
- Any lesson may be attached to a named progression or marked `untracked`.
- `primitive-generative-drawing` is one optional seed progression, not the required curriculum spine.
- The core teaching loop remains **Control -> Bend -> Recover** when useful.
- Visual explanations should use labeled diagrams, visual maps, storyboards, thumbnail plans, component specs, primitive relationship matrices, or pattern deformation maps.
